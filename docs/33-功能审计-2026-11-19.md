## 2. 复验后排除（代理报了，但复验不成立）

- **风险徽章未应用多因子矩阵**：`riskOf` 读取的是宿主行字段 `risk`，而行构造时已用
  `riskLevel(ratio, point, cfg, logStats)` 完成矩阵判定——客户端无需重复计算。误报。
- **价格簿失败退避卡死**：失败后每 60 秒重试一次并自动恢复，不是永久卡死。误报。

## 3. 审计确认无问题的部分

- **注入面**：无 innerHTML / dangerouslySetInnerHTML / insertAdjacentHTML；无动态 RegExp 构造。
- **时区**：`isPeakTime` 用固定 UTC+8 偏移（中国无夏令时），工作日与小时边界正确。
- **格式化**：`pct` / `fmt` 对 null / 非法输入返回「—」，不抛错。
- **缓存失效**：LOG_SPLITS 的 mtime/size 判据、增长节流 60 秒冷却、DTO 缓存删除点完整；
  persistence `read()` 返回全量事件不过滤类型，检查点计数前提成立。
- **计数管线**：真实日志经同款管线验证（分镜规划会话 12 次 = 11 剪枝 + 1 全量）。
